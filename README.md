# レシピ帳 / Kitchen Recipe Book

厨房用のレシピカードを登録・管理して、そのまま印刷（PDF保存）できるWebアプリです。

## できること
- レシピの登録（料理名 日本語／English、カテゴリー、調理時間）
- 写真の添付（スマホならその場で撮影）
- 材料ごとの原価 → 1皿の原価・原価率・利益を自動計算
- 作り方（日本語＋英語）、提供時に必要なもの、アレルギー、メモ
- カテゴリー分け（アペタイザー、揚げ物など。設定で自由に追加・変更）
- 1枚ずつ、またはまとめて印刷（ハーフレター 5.5×8.5インチ／レター／A5／A4）
- 原価を印刷する／しない（スタッフ配布用）の切り替え
- バックアップの書き出し・読み込み（別の端末へ移すときにも使用）

## 使い方
`index.html` をブラウザで開くだけで動きます。
レシピはその端末のブラウザ内に保存されます。

## 印刷のコツ
印刷画面で「PDFに保存」を選ぶとPDFになります。
「余白：デフォルト」「背景のグラフィック：オン」にするときれいに出ます。
